# 学生2模块接口与匹配说明

服务默认监听本机 `127.0.0.1:8765`。`GET /api/health`返回模型状态、来源、类别和匹配方法。`GET /api/samples`返回内置样例清单。`POST /api/predict`采用multipart/form-data。

| 字段 | 含义 | 默认值 |
| --- | --- | --- |
| file | 原始车辆图片，必填 | 无 |
| mode | parts、auto或external | parts |
| partConfidence | 部件模型置信度阈值 | 0.25 |
| damageConfidence | auto模式的损伤模型置信度阈值 | 0.25 |
| minCoverage | 接受匹配的最低覆盖率 | 0.35 |
| damagesJson | external模式的损伤数组，或含damages字段的对象 | 无 |

外部损伤的每一项应有 `damageType` 和 `bbox`，可有 `confidence`。类型使用 `dent`、`scratch`、`crack`、`glass_shatter`、`lamp_broken`、`tire_flat`；其他非空类型可输入，但不应用车灯等语义限制。坐标采用EXIF纠正后原图的 `[x1,y1,x2,y2]` 像素值，满足 `0≤x1<x2≤width` 和 `0≤y1<y2≤height`。不接受NaN、无穷值、框越界及负面积。

返回的 `parts` 包含实例编号、部件编码、中文名称、业务类别、原始标签、候选标签、置信度、框、分割面积和轮廓。`damages` 包含原始损伤输入、关联部件、交集比例、框IoU、部件损伤占比和候选列表。原图与标注图URL可直接展示。

置信度保留原始模型分数，未经概率校准。合并侧别冲突后，分数仍为最高原始预测分数，不应解释成通用类别的校准准确率。

匹配顺序如下：

1. 识别部件，排除通用object；按同家族掩膜IoU合并重复实体。
2. 计算损伤掩膜与部件掩膜交集。外部损伤只有框时，将框转换为栅格区域。没有掩膜时退化为框交集。
3. 对车灯破损、玻璃破碎、轮胎异常分别限制匹配到light、glass、wheel部件。该限制依据损伤模型类别，并不证明该类别正确。
4. 对相容候选，按损伤覆盖率、框IoU、部件模型置信度依次排序。
5. 最优覆盖率不足阈值则返回unknown。多个候选都达到阈值则保留multiple_parts及候选信息，便于人工复核。

覆盖率为交集面积除以损伤面积；部件损伤占比为交集面积除以部件面积。部件占比只描述二维可见区域，不能代表真实凹陷深度或结构受损程度。

匹配状态：`matched`为规则接受一个主部件；`multiple_parts`为多个相容部件达到阈值；`unmatched`为不能可靠定位。这些状态表示匹配规则的决定，不是经过人工真值确认的正确与错误分类。

Python直接调用：

```python
from PIL import Image, ImageOps
from ai.pipeline import Pipeline

pipeline = Pipeline()
with Image.open('samples/damage-4.jpg') as source:
    image = ImageOps.exif_transpose(source).convert('RGB')
    result = pipeline.predict(image, mode='external', external=[
        {'damageType':'dent','confidence':0.9,'bbox':[390,335,510,440]}
    ])
print(result['damages'])
```

独立的 `ai.matching.match_damage` 不依赖YOLO或服务器，只依赖NumPy，可直接集成到其他AI流水线。部件掩膜和损伤掩膜必须在相同原图坐标系、具有相同尺寸。
