# 02 网页与命令行演示

本章先运行已经准备好的公开模型，不需要下载整个训练数据集。前提是[环境检查](01-从零安装与环境检查.md)已经通过。

## 第一步 启动本地网页服务

在工程根目录执行：

```powershell
& .\start.ps1
```

也可双击`start.cmd`。成功时应看到`Student 2 demo is running: http://127.0.0.1:8765`，浏览器自动打开页面。若不希望自动开浏览器，执行`& .\start.ps1 -NoBrowser`。

检查服务是否就绪：

```powershell
Invoke-RestMethod 'http://127.0.0.1:8765/api/health'
```

应返回`status=ok`、模型信息和`serverPid`。端口8765是本地端口；把地址发给另一台电脑，不会让那台电脑访问到你的本地服务。

## 第二步 做一次部件识别

1. 页面左侧选择“部件1”或“损伤4”样例。
2. 把演示模式改为“仅识别车辆部件”。
3. 保持部件置信度0.25。
4. 点击“开始识别与定位”。
5. 在右侧“部件分割”查看彩色区域，在“部件明细”查看名称、类别和置信度。

此时输入损伤数应为0，系统只演示学生2的部件识别。原始模型若在同一区域同时预测左右门，结果可能显示“前车门，侧别未确定”；这是对冲突输出的保留，不代表算法已经正确判断了左右。

## 第三步 做一次自动联调

选择“损伤4”，模式改为“部件识别 + 自动损伤匹配”，保持三个阈值为0.25、0.25、0.35，点击开始。

切换右侧“损伤定位”和下方“损伤与部件关联”。固定权重与样例下，初版记录识别到7个合并后部件，1处凹陷关联到前保险杠。损伤覆盖率约98.6%，部件损伤占比约19.5%。耗时会随机器与是否首次加载改变。

这一步的损伤输入来自公开CarDD模型。学生2完成的是部件识别与空间关联，不能把损伤模型的训练写成自己的工作。

## 第四步 接入学生1的损伤框

仍选择“损伤4”，把模式改为“接入外部损伤框（学生1）”，将下面的JSON粘贴到输入框：

```json
[{"damageType":"dent","confidence":0.9,"bbox":[390,335,510,440]}]
```

点击开始，再查看关联表。这个框是针对`damage-4.jpg`这张791×592图片提供的联调例子，不能原样复制到其他照片。外部框模式使用矩形区域与部件掩膜求交，因此计算值不必与自动损伤掩膜模式完全相同。

把框改成明显越界的`[0,0,9999,9999]`再运行，应显示坐标范围错误。这是输入验证的检查，不能把越界框自动裁剪后当成原始正确输入。

## 第五步 上传自己的照片

点击选择车辆照片，或把图片拖进上传区域。支持JPEG、PNG和WebP；单张最大12MB、最多800万像素。超出时先缩小图片。尽量拍清整块部件及相邻边界，局部特写可能无法识别部件。

模型没有检测到部件时，会保留空结果。损伤没有足够部件覆盖时，会显示“部位待确认”。这两种结果都不能直接解释成车辆没有损伤。

## 第六步 导出并查看JSON

运行成功后点击“导出JSON”。浏览器下载的文件包含本次图片尺寸、模式、部件、损伤、候选、阈值和模型信息。

每个部件的`bbox`是矩形，`polygons`是展示用轮廓，`areaPixels`是分割区域像素数。每个损伤的`matchCoverage`表示部件覆盖损伤的比例，`damageRatio`表示损伤交集占部件面积的比例。二者分母不同。

## 第七步 不启动网页也能运行

```powershell
& .\.venv\Scripts\python.exe scripts/run_demo.py --image samples/parts-1.jpg --mode parts --output results/tutorial-runs/parts
& .\.venv\Scripts\python.exe scripts/run_demo.py --image samples/damage-4.jpg --mode auto --output results/tutorial-runs/auto
& .\.venv\Scripts\python.exe scripts/run_demo.py --image samples/damage-4.jpg --mode external --damages-json config/student1-example.json --output results/tutorial-runs/external
```

输出目录内有JSON、原图、部件图和关联图。第三条命令不会运行损伤模型，它读取明确提供的外部框。

调整参数的例子：

```powershell
& .\.venv\Scripts\python.exe scripts/run_demo.py --image samples/damage-4.jpg --mode auto --part-confidence 0.4 --min-coverage 0.5 --output results/tutorial-runs/threshold-change
```

不要只比较“数量变多了”，还要观察误检、遗漏和unknown是否变化。提高置信度可能减少误检，也可能漏掉真实部件。

## 第八步 停止与重启

```powershell
& .\stop.ps1
& .\start.ps1
```

关闭浏览器不会自动停止后台Python服务。启动日志在`data/server.log`和`data/server-error.log`；这两个文件是本机运行文件，默认不提交到GitHub。

本章验收：三个模式均运行过；能找到一张标注图和一个JSON；能解释一次成功与一次失败；停止与重启都成功。
