## 已观察到的局限与处理

近距离照片parts-2未检测到部件，保持空结果和unknown匹配。同一车门或车灯区域有时同时预测左、右标签，已合并重复掩膜并显示侧别未确定。损伤1的车灯破损输入没有可靠的车灯部件，增加语义相容约束后保留unknown，避免关联到尾门。

模型仍可能把部件识别成错误类别，或漏掉遮挡与严重变形部件。空间匹配不能纠正所有上游类别错误。后续应另建人工标注的损伤与部件关联测试集，分别统计部件分类、侧别、掩膜质量、主部件匹配与跨部件损伤的正确率。

## 复现

重新运行自动测试与样例：

```powershell
.venv/Scripts/python.exe -m pytest -q
.venv/Scripts/python.exe scripts/batch_test.py
```

从 [官方Carparts-seg链接](https://docs.ultralytics.com/datasets/segment/carparts-seg/)取得数据后，重新计算公开模型指标：

```powershell
.venv/Scripts/python.exe scripts/evaluate_public_test.py --dataset C:/data/carparts-seg
```

当前电脑的数据目录记录在 `results/dataset10-summary.json`。数据、权重、阈值或推理分辨率变化后，指标可能变化。
